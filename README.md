# 🎓 Student Details Management System

A beginner-friendly C programming project that stores and displays details of 10 students using structures, arrays, loops, and functions.

## 📌 Features

- Collects details of 10 students
- Stores student name, roll number, marks, city, and dream
- Uses structures to organize student information
- Uses separate functions for input and display
- Displays student records in a formatted layout
- Supports spaces in names, cities, and dreams

## 🛠️ Technologies Used

- **Language:** C
- **Compiler:** GCC
- **Editor:** Visual Studio Code

## 📋 Student Information

The program collects the following details:

1. Name
2. Roll Number
3. Marks
4. City
5. Dream

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the program:

   ```bash
   gcc student_details.c -o student_details
   ```

5. Run on Windows PowerShell:

   ```powershell
   .\student_details.exe
   ```

## 📚 Concepts Practiced

- Structures (`struct`)
- Arrays of structures
- Functions
- `for` loops
- Input and output using `scanf()` and `printf()`

## 🎯 Project Objective

To practice fundamental C programming concepts by building a simple student information management system.
